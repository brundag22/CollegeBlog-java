# College Blog Application

## Abstract
The College Blog Application is a role-based academic portal designed to facilitate digital interaction between educators and students. Developed as a comprehensive college project, the system streamlines the distribution of study materials, assignment tracking, interactive assessments, and attendance monitoring within a unified platform.

## Features

### Teacher Module
* Authentication: Secure session-based login.
* Study Materials: Upload and manage educational resources (PDF, DOCX, TXT).
* Assignments: Formulate assignments with descriptions and review file-based student submissions.
* Assessments: Design multiple-choice quizzes and evaluate student performance via automated grading.
* Attendance: Record and track daily student attendance metrics.

### Student Module
* Authentication: Secure session-based login.
* Study Materials: Access and download instructor-uploaded academic notes.
* Assignments: View pending assignments and upload file-based submissions.
* Assessments: Participate in quizzes and view instantaneous evaluation results.
* Attendance: Monitor personal attendance history.

## Technology Stack
* Backend Framework: Java 17, Spring Boot 3.x
* Data Access Layer: Spring Data JPA, Hibernate
* Database Management: MySQL 8.x
* Frontend Template Engine: Thymeleaf
* User Interface: HTML5, CSS3, Bootstrap 5
* Build Tool: Maven (Wrapper)
* Version Control: Git, GitHub

## System Requirements
* Java Development Kit (JDK) 17 or higher
* MySQL Server (Port 3306)
* Command Line Interface (CMD)
